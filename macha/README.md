# macha — WireWarp Zig backend

For ordinary use, open a local backup world, leave tModLoader waiting, then double-click `Setup.cmd`. It finds a complete world export pair (or accepts a custom path), calls the V4.1 builder and launches the backend only after success. On subsequent sessions with an unchanged graph, double-click `Launch.cmd` instead. If the graph changes (including changes to saved tile/device state), rerun Setup. No benchmark is required. Use Python 3.12 and Zig 0.16.0 on PATH for setup. The existing backend executable does not need Python or Zig to launch.

Advanced: `BuildV42.cmd` shows the mode menu. `BuildV42.cmd generic` explicitly clears AOT; `BuildV42.cmd v4.1` selects the recommended engine (v4.0 and v3.5 retained). Set `WWORLD` to the exact exported prefix, without extension. `ResolveWorld.cmd` resolves the legacy default `world` pair only; Setup discovers arbitrary names. `BuildV42.cmd /nopause` requires a mode and otherwise fails without changing generated source. `Setup.cmd /nopause` requires WWORLD or exactly one discovered pair; `Launch.cmd /nopause` does not build. The executable is `zig-out/bin/macha.exe serve`. Confirm matching graph hashes and actual mode in the console. The SHA guard remains unchanged.

Developer-only: `Validate.cmd` runs all tests and builds generic, clearing AOT; RC1/RC2/RC3 validation aliases remain. `InitializeAOT.cmd` and `BenchmarkRGB.cmd` are historical RGB-specific; `BenchmarkV42.cmd` runs synthetic fixtures.
