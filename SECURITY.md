# Security

WireWarp is intended for a trusted local frontend and backend on a user's own machine. Named-pipe message checks and graph hashes are not authentication or a security sandbox. Do not expose the IPC channel to untrusted peers. Use trusted source/builds and test worlds; do not run the mod or backend with elevated privileges unnecessarily.

Report suspected vulnerabilities privately to the repository maintainer via GitHub private vulnerability reporting if enabled, or a maintainer-confirmed private contact. Do not post exploitable details, private graph files, personal paths or sensitive logs publicly. Include affected version, reproducible steps and impact. No support SLA is promised. Enable a private reporting channel before public release.
