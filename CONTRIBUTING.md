# Contributing

Open an issue before changing scheduling, RNG, tile behavior, IPC or supported versions. Preserve exact ordered activations, wave boundaries, fault state, graph guards and native mechanics. Use a backed-up world. Keep the generic backend and reference frontend available. Never publish private world exports, calibration profiles, captures, personal paths or handoff archives.

Run `macha/Validate.cmd`, then any relevant native graph parity and live tests. Include exact compiler/game versions, actual backend and frontend modes, commands and reproducible evidence. Report failures and skipped tests. Benchmark the same graph and trace; distinguish headless time from draw-callback rates. Document changes and update tests. Contributions are intended to be GPL-3.0-only; submit only material you have rights to license. Do not submit proprietary game source or assets.
